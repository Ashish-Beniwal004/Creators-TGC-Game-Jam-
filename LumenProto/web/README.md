# Lumen Web Engine

This directory contains the native JavaScript WebGL implementation of Lumen, fulfilling the final technical requirement of the TGC GameJam submission.

## Purpose
While the primary `LumenProto` directory contains the Godot 4 reference prototype (used for mechanical design and collision validation), this `web/` project is the intended target architecture for the final, browser-playable game deployable to itch.io.

## Technology Stack
- **Three.js**: Used for rendering 2D/2.5D visual layers, handling the camera, and applying the future comic-book shaders.
- **InstancedBufferGeometry**: Used within `src/systems/ParticleSystem.js` to efficiently render thousands of floating background spores/dust motes in a single draw call.
- **Matter.js**: Replaces Godot's Box2D/physics engine to provide native browser-based rigid body simulation and platforming collision.
- **Vite**: The build tool and development server.

## Installation & Running
```bash
# Install dependencies
npm install

# Run the development server
npm run dev

# Build the production package (outputs to dist/)
npm run build
```

## Architecture
- `game/`: The core game loop and state management.
- `rendering/`: Three.js WebGL renderer, camera controller, and scene management.
- `physics/`: Matter.js simulation wrapping.
- `entities/`: Player and enemy logic, acting as the bridge between Matter.js bodies and Three.js visual meshes.
- `systems/`: Input handling and instanced particle systems.

## Asset Pipeline
This web engine dynamically loads the `.webp` files generated by the `asset_pipeline` in the parent directory. It pulls from `assets/web/`.

## Itch.io Deployment
Running `npm run build` generates a `dist/` directory that is fully self-contained. The `index.html` and bundled JS use relative paths, making it safely embeddable within an itch.io HTML iframe upload.
